# puzzllm levels. One block per level; see src/levels.h for the format.
# A later level is a new block here, not new code.

level: 1
title: Hello, world
room: stone
goal: Get the agent to create hello_world.txt saying Hello, World!
hint: Walk to the big omp screen on the left and press Enter to talk to the agent.
hint: Ask plainly: create a file named hello_world.txt containing Hello, World!
hint: Small models sometimes say they did it when they did not. Check with ls in the shell.
hint: If it wrote the wrong file, tell it exactly what went wrong and ask again.
hint: You may also finish the goal yourself in the shell, bottom right.
check: file hello_world.txt
require: nonempty
require: contains-ci hello
require: contains-ci world
require: max-bytes 4096

level: 2
title: The carwash
room: brick
goal: Get the agent to write carwash.txt: you must drive to the carwash, because the car has to be there.
hint: Ask: My car is dirty and the carwash is 50 m away. Walk or drive? Write your answer to carwash.txt.
hint: Small models often answer walk, because it is close. But what gets washed?
hint: If it says walk, ask it how the car gets washed if the car stays at home.
hint: The file must name the carwash, say drive, and give a reason (because...). It must not say to walk.
hint: Check with cat carwash.txt in the shell. The check reads the file, not the chat.
hint: You may also write the statement yourself in the shell, bottom right.
check: file carwash.txt
require: nonempty
require: max-bytes 4096
require: lacks-ci should walk | better to walk | recommend walking | walking is better | walk instead
require: contains-any-ci carwash | car wash | car-wash
require: contains-any-ci drive | driving | drove
require: contains-any-ci because | since | so that | otherwise | has to be | must be | needs to be | need to be

level: 3
title: A million ones
room: brick
goal: Make 1.txt hold exactly 1,000,000 ones and nothing else: no spaces, no line ending.
hint: Nobody types a million characters. Ask the agent to make the file with a command or a short program.
hint: echo and print add a line ending at the end, and that one extra byte fails the goal.
hint: Check in the shell: wc -c 1.txt must say 1000000, and tr -d 1 < 1.txt | wc -c must say 0.
hint: Small models miscount. If the size is wrong, tell the agent the exact size wc -c reports.
hint: One way: head -c 1000000 /dev/zero | tr '\0' 1 > 1.txt
hint: Another: python3 -c "open('1.txt', 'w').write('1' * 1000000)"
hint: You may also finish the goal yourself in the shell, bottom right.
check: file 1.txt
require: bytes 1000000
require: only 1

level: 4
title: The treasure chest
room: stone
goal: Open the password-protected chest.zip and extract key.txt to unlock the door.
hint: The password is lowercase.
hint: The password is four letters long.
hint: In the shell, run unzip chest.zip and enter a candidate when prompted.
check: chest
