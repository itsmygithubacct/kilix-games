# puzzllm levels. One block per level; see src/levels.h for the format.
# A later level is a new block here, not new code.

level: 1
title: Hello, world
room: stone
goal: Get the agent to write Hello, World! to ~/hello_world.txt.
hint: Walk to the agent screen on the left and press Enter to talk to the agent.
hint: Ask it to create hello_world.txt in ~, the current directory, containing Hello, World!
hint: The agent can say it wrote the file even when the file is missing. Check with ls ~ in the shell.
hint: If it wrote the wrong file, tell it exactly what went wrong and ask again.
hint: You may also finish the goal yourself in the shell, bottom right.
check: file hello_world.txt
require: nonempty
require: contains-ci hello
require: contains-ci world
require: max-bytes 4096

level: 2
title: Strawberry
room: brick
goal: Get the agent to count the r's in strawberry and write the number to ~/strawberry.txt.
hint: Ask the agent to count every r and write only the number to strawberry.txt in ~.
hint: Spell strawberry one letter at a time. Count each r, including repeated letters.
hint: The agent can use a program to count occurrences in the string strawberry.
hint: Check the file in the shell with cat ~/strawberry.txt.
check: file strawberry.txt
require: max-bytes 32
require: equals 3

level: 3
title: A million ones
room: press
goal: Make 1.txt hold exactly 1,000,000 ones and nothing else: no spaces, no line ending.
hint: Nobody types a million characters. Ask the agent to make the file with a command or a short program.
hint: echo and print add a line ending at the end, and that one extra byte fails the goal.
hint: Check in the shell: wc -c 1.txt must say 1000000, and tr -d 1 < 1.txt | wc -c must say 0.
hint: Small models miscount. If the size is wrong, tell the agent the exact size wc -c reports.
hint: One way: head -c 1000000 /dev/zero | tr '\0' 1 > 1.txt
hint: Another: python3 -c "open('1.txt', 'w').write('1' * 1000000)"
hint: You may also finish the goal yourself in the shell, bottom right.
check: file 1.txt
require: bytes 1000000
require: only 1

level: 4
title: Count the files
room: archive
goal: Fix ~/count_files.sh. From ~, running it with Bash should print the number of regular files directly inside "sample files". It should also accept a folder path as its first argument.
hint: Run bash count_files.sh in ~, then compare its output with ls -la "sample files".
hint: A hidden regular file counts. Folders, their contents, and symlinks do not count.
hint: Look at what happens when the file test receives a path containing spaces.
hint: Try bash count_files.sh "/tmp/empty folder" after making that directory in the shell. An empty directory should print 0.
check: count-files

level: 5
title: The treasure chest
room: vault
goal: Open the password-protected chest.zip and extract key.txt to unlock the door.
hint: The password is lowercase.
hint: The password is four letters long.
hint: In the shell, run unzip chest.zip and enter a candidate when prompted.
hint: Run man unzip in the shell to see the command options.
check: chest

level: 6
title: Follow the log
room: dock
goal: Run ./run_check.sh in the player shell. Ask the agent to read the latest failure and write its run ID and failing filename to ~/report.txt, separated by one space.
hint: Use the Shell log button to give the agent the path to the shell transcript.
hint: The agent can also read the player shell with tmux capture-pane -p -S - -t shell.
hint: Every run creates a new ID. Copy the ID and filename from the same failure line.
check: follow-log

level: 7
title: The seal
room: stone
goal: Write ~/seal.txt by repeating the lowercase letters whose alphabet positions are multiples of 3, in order, to exactly 32 bytes, with no line ending and no other bytes.
hint: Alphabet positions start at 1: a is 1, b is 2, c is 3. Keep a letter when its position is a multiple of 3.
hint: Take those letters in alphabet order. That cycle has eight letters. Repeat the cycle from the start.
hint: seal.txt is only those repeated letters. No spaces, no label, and no line ending. The file is exactly 32 bytes.
hint: echo and print add a line ending, and that extra byte fails the goal. Write the bytes and stop.
hint: In the shell, wc -c seal.txt must print 32. A trailing line ending makes it 33.
hint: You may also finish the goal yourself in the shell, bottom right.
check: file seal.txt
require: bytes 32
require: only cfilorux
require: equals cfiloruxcfiloruxcfiloruxcfilorux

level: 8
title: The mirror
room: brick
goal: Write ~/mirror.txt as the 32-byte seal from room 7, then one comma, then those same 32 bytes reversed. Exactly 65 bytes, with no line ending and no other bytes.
hint: Build the room 7 seal first: eight letters, repeated to 32 bytes, no line ending.
hint: The file is the seal, one comma, then the seal reversed. The comma is the only byte that is not a letter.
hint: Reversing by words or by cycles is wrong. Reverse the 32 characters one by one.
hint: 32 plus 32 is 64. The comma makes 65. A line ending makes 66.
hint: In the shell, wc -c mirror.txt must print 65.
hint: You may also finish the goal yourself in the shell, bottom right.
check: file mirror.txt
require: bytes 65
require: only cfilorux,
require: equals cfiloruxcfiloruxcfiloruxcfilorux,xurolifcxurolifcxurolifcxurolifc
