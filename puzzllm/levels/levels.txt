# puzzllm levels. One block per level; see src/levels.h for the format.
# A later level is a new block here, not new code.

level: 1
title: Hello, world
room: stone
goal: Get the agent to write Hello, World! to ~/workspace/hello_world.txt.
hint: Walk to the agent screen on the left and press Enter to talk to the agent.
hint: Ask it to create hello_world.txt in ~/workspace, the current directory, containing Hello, World!
hint: The agent can say it wrote the file even when the file is missing. Check with ls ~/workspace in the shell.
hint: If it wrote the wrong file, tell it exactly what went wrong and ask again.
hint: You may also finish the goal yourself in the shell, bottom right.
check: file hello_world.txt
require: nonempty
require: contains-ci hello
require: contains-ci world
require: max-bytes 4096

level: 2
title: Strawberry
room: brick
goal: Get the agent to count the r's in strawberry and write the number to ~/workspace/strawberry.txt.
hint: Ask the agent to count every r and write only the number to strawberry.txt in ~/workspace.
hint: Spell strawberry one letter at a time. Count each r, including repeated letters.
hint: The agent can use a program to count occurrences in the string strawberry.
hint: Check the file in the shell with cat ~/workspace/strawberry.txt.
check: file strawberry.txt
require: max-bytes 32
require: equals 3

level: 3
title: A million ones
room: brick
goal: Make 1.txt hold exactly 1,000,000 ones and nothing else: no spaces, no line ending.
hint: Nobody types a million characters. Ask the agent to make the file with a command or a short program.
hint: echo and print add a line ending at the end, and that one extra byte fails the goal.
hint: Check in the shell: wc -c 1.txt must say 1000000, and tr -d 1 < 1.txt | wc -c must say 0.
hint: Small models miscount. If the size is wrong, tell the agent the exact size wc -c reports.
hint: One way: head -c 1000000 /dev/zero | tr '\0' 1 > 1.txt
hint: Another: python3 -c "open('1.txt', 'w').write('1' * 1000000)"
hint: You may also finish the goal yourself in the shell, bottom right.
check: file 1.txt
require: bytes 1000000
require: only 1

level: 4
title: The treasure chest
room: stone
goal: Open the password-protected chest.zip and extract key.txt to unlock the door.
hint: The password is lowercase.
hint: The password is four letters long.
hint: In the shell, run unzip chest.zip and enter a candidate when prompted.
check: chest

level: 5
title: Count the files
room: brick
goal: Fix ~/workspace/count_files.sh. From ~/workspace, running it with Bash should print the number of regular files directly inside "sample files". It should also accept a folder path as its first argument.
hint: Run bash count_files.sh in ~/workspace, then compare its output with ls -la "sample files".
hint: A hidden regular file counts. Folders, their contents, and symlinks do not count.
hint: Look at what happens when the file test receives a path containing spaces.
hint: Try bash count_files.sh "/tmp/empty folder" after making that directory in the shell. An empty directory should print 0.
check: count-files
